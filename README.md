# Core Python Programming Assignment

This repository contains solutions for the Core Python Programming Assignment.

## Programs

1. **E-Commerce Cart System** - Calculates cart total and applies a 10% discount when more than 5 items are present.
2. **Restaurant Menu Management** - Adds, removes, and checks menu items.
3. **Classroom Performance Tracker** - Calculates student averages and identifies the top performer.
4. **Movie Ticket Booking System** - Manages booked and available cinema seats.
5. **Hospital Patient Management** - Stores patient records and searches by disease.
6. **Customer Feedback Analysis** - Calculates the percentage of positive customer feedback.
7. **Taxi Fare Calculation** - Calculates fares for multiple taxi trips.
